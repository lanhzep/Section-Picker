# Section-Picker
incoming students see sections with adviser, room, seats left and a weekly schedule, then pick one, or join a waitlist when it is full.
The Section Picker is a user-friendly web app for incoming students and parents to browse class sections—viewing the adviser, room, available seats, and weekly schedule—and either claim a spot or join a waitlist when full. Built with HTML/CSS/JavaScript. The interface, seat tracking, "pick" action, and waitlist queue all work smoothly. However, because it lacks a shared backend database, seat counts don't sync across different devices, and it is still missing an admin panel, student logins, and automated waitlist emails.
I use Deepseek for coding and asking step by step process.
